She Footy
Sitio web oficial de She Footy, plataforma de contenido sobre fútbol femenino global.
Reglas de trabajo

* `index.html` es la landing page actualmente en producción.
* Realiza únicamente los cambios que solicite. No modifiques otras secciones, textos, estilos o funcionalidades sin autorización.
* Preserva siempre el diseño existente, responsive y funcionalidad.
* Antes de modificar, revisa solo los archivos necesarios para la tarea.
* Haz cambios mínimos y precisos; evita reescribir archivos completos innecesariamente.
* No generes explicaciones extensas. Al terminar, informa brevemente qué cambiaste.
* No crees archivos, dependencias o frameworks innecesarios.
* Mantén el código limpio y ligero.
* El repositorio usa Git y la rama de producción es `main`.
* El sitio se despliega desde GitHub mediante Vercel.
* Cuando termines un cambio aprobado, prepara el commit correspondiente.
* No hagas cambios adicionales para "mejorar" la página salvo que se soliciten expresamente.
